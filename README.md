# PHTML Runtime

PHTML Runtime is an agentic HTML presentation runtime.

Goals:
- Single HTML presentation runtime
- Editable directly in browser
- JSON-based deck structure
- Lightweight sharing without installation
- Agent-assisted presentation workflow

## Architecture

```text
PHTML Runtime
├── runtime/   # Core editor and presentation engine
├── themes/    # Visual themes
├── decks/     # Presentation content JSON
└── examples/  # Example presentations
```

## Vision

PHTML aims to combine:
- PPT-like editing
- Web-level visuals and responsiveness
- Agentic workflows
- Real-time presentation updates
- Easy sharing with a single HTML file
